# 全部锁死版本，不用 >= 或 ^。
#
# 原因：Dockerfile 里 `COPY requirements.txt .` 这一层只在文件变化时才重建，
# 用范围版本号就意味着「每次重建都可能装上这期间发布的所有新版本」——
# 上游一个不兼容的新版就能让构建突然失败，而且极难排查。
# 锁死后每次构建装的东西完全一样，出问题也能确定不是依赖变动引起的。
#
# 升级方式：改版本号 → 本地跑一遍 → 构建通过再提交。
